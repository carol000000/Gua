# GUA 專案頁面模板

這個專案已提供可直接複製的頁面模板：

- HTML 範本： [html/template.html](html/template.html)
- CSS 範本： [css/template.css](css/template.css)

## 使用方式
1. 複製 [html/template.html](html/template.html) 內容。
2. 另存為新的頁面檔案，並放到 [html](html) 目錄下。
3. 把標題、內容區塊與卡片內容替換成你的新頁面內容。
4. 確認新頁面引用了 [css/template.css](css/template.css)。

## 建議修改的位置
- `title`：頁面標題
- `.banner h1`：主標題
- `.banner p`：副標題
- `.section-block`：內容區塊
- `.info-card`：卡片內容
